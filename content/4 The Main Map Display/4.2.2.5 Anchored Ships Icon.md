#### 4.2.2.5 Anchored Ships Icon

Ports can exist in a base which has access to lakes, rivers, and the ocean. Ships which are disbanded in a port are anchored. In game terms, ports which have not yet been developed to level 1 capacity are anchorages. Where there are anchored ships, the following icon is displayed on the Tactical Map:

The anchored ship’s icon is found in the upper left of the hex.  The color of the icon varies depending on the nationality of the ships anchored there.
