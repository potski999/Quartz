## 1.3 Editor Manual

*War in Spain 1936-39* has an editor feature that allows you to create your own scenarios anywhere on the **War in Spain 1936-39** map.

**Details on how to use the editor are contained in the separate PDF editor manual file which is in the manuals sub directory of your War in Spain 1936** - 39 installation.  Access to the editor itself is through the scenario editor button within the game.
