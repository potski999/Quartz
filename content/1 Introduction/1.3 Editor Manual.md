## 1.3 Editor Manual

*War in Spain 1936-39* has an editor feature that allows you to create your own scenarios anywhere on the War in Spain 1936-39 map. **Details on how to use the editor are contained in the separate PDF editor manual file which is in the manuals sub directory of your War in Spain 1936** - 39 installation.  Access to the editor itself is through the scenario editor button within the game.
### 1.3.1 User Created Scenarios

Any user created scenarios can only be saved to a slot after 25, as the first 25 scenario slots are reserved exclusively for official scenarios.
