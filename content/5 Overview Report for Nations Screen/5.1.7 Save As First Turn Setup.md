### 5.1.7 Save As First Turn Setup

Allows you to save your current first turn as a “Special First Turn Setup”. The file is Scenario specific and can hold data for both sides. So, you can store orders for both sides when giving orders in H2H mode. Certain commands that would create new units cannot be stored for later import, but all orders you give for existent units can be retrieved later.
