## 8.7 Ground Units and Fortifications

LCU’s that are in a base hex assume the fortification level of the base. Unless the LCU’s in the hex have a higher fortification level than the base hex they are in. LCU’s that are not in a base and are not moving will automatically attempt to build fortifications to protect themselves from attacking enemy LCU’s. These fortifications can be built up to a maximum of level 3 and cannot be built in any terrain, nor will they be built at the same speed in every terrain hex that is allowed. LCU’s can only fortify themselves, in the following terrain types, to the indicated maximum level:

| TERRIAN TYPE      | MAXIMUM FORT LEVEL |
| ----------------- | ------------------ |
| Plains/Clear      | 3                  |
| Rough             | 3                  |
| Forest            | 1                  |
| Rough Forest      | 1                  |
| Jungle            | 1                  |
| Rough Jungle      | 1                  |
| Desert            | 3                  |
| Rough Desert      | 3                  |
| Sand Desert       | 3                  |
| Mountain          | 1                  |
| Tropical Mountain | 1                  |
| Developed         | 3                  |
| Cultivated        | 3                  |
| Salt Marsh        | 3                  |
| Swamp             | 1                  |
