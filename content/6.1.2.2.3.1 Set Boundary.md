###### 6.1.2.2.3.1 Set Boundary

Three Set Boundary options allow the player to patrol within a single hex, Set Boundary 1, only, patrol along a line, Set Boundary 1 and 2, and  patrol  along  the  perimeter  of  an  area;  Set  Boundary  1,  2,  and  3. Clicking the arrow to the left of each of these titles causes the screen to be replaced by a large display of the tactical map; scroll around and click on a hex in order to set that boundary.
